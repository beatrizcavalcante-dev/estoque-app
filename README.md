# 📦 Stock — Sistema de Gerenciamento de Estoque

Sistema web de controle de estoque com design moderno, desenvolvido com HTML, CSS, JavaScript e Node.js.

## 🔗 Acesse o projeto

> Em breve disponível online

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- SQLite

## 💡 Sobre o projeto

Sistema completo de gerenciamento de estoque desenvolvido do zero, com foco em aprendizado prático de desenvolvimento web full-stack. O projeto contempla front-end responsivo, back-end com API REST e banco de dados relacional.

## ✨ Funcionalidades

- Dashboard com métricas em tempo real
- Cadastro, edição e exclusão de produtos
- Registro de entradas e saídas de estoque
- Histórico de movimentações com filtros
- Busca de produtos em tempo real
- Alertas de estoque baixo
- Layout responsivo para mobile
